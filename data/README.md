# Capstone Datasets (Review 1)

This directory contains the raw datasets assigned for Review 1 of the 23CSE301 ML Capstone project.

## 1. Ames Housing Dataset (Regression Track)
- **File:** `housing.csv`
- **Rows:** 2,930
- **Features:** 81 explanatory variables
- **Target:** `SalePrice` (Continuous home sale price in USD)
- **Origin:** Ames Assessor's Office (Dean De Cock, 2011)

## 2. Online Shoppers Purchasing Intention (Classification Track - Part A)
- **File:** `online_shoppers_intention.csv`
- **Rows:** 12,330
- **Features:** 17 session and behavioural features
- **Target:** `Revenue` (Binary: True / False)
- **Class Balance:** 84.5% No Purchase / 15.5% Purchase (Imbalanced)
- **Origin:** UCI Machine Learning Repository (Sakar et al., 2019)
